# TASK_041 — Экран «Операции по категории»: визуальное продолжение Home

**Статус:** DONE (реализация и локальные проверки завершены; commit/push —
после визуального подтверждения пользователем на реальном iPhone, по
прямому требованию постановки)

## Цель

Экран просмотра операций по категории (`#catTxOverlay`, открывается тапом по
категории в Аналитике/Бюджетах — например «🛒 Продукты») должен визуально и
по UX ощущаться прямым продолжением Главной, а не отдельной страницей со
своим стилем. Точечная визуально-UX задача по прямому запросу пользователя,
вне очереди `TASK_025` §12 (тот же приём, что `TASK_039`/`TASK_038A`).

## Границы работы

Изменять **только** вёрстку/стили `#catTxOverlay` и вспомогательные функции
рендера его списка операций. Не менять:
- расчёты (`catTxRange`, суммы, средние, фильтрацию по `catTxIds`);
- данные, storage, CRUD;
- другие экраны (Главная, Аналитика, Бюджеты, «Все операции», Счета) —
  общие `.tx`/`.daycard`/`groupedTxHtml`/`dayLabelFull`/`.detail-sheet`
  остаются без изменений, используются другими экранами как прежде;
- навигационную бизнес-логику (точка входа/выхода из экрана).

## Требования (по ТЗ пользователя)

1. Кнопка «Назад» — убрать `×`, круглая iOS-кнопка слева, крупный шеврон
   `‹`, 44–48px, светлый фон, мягкая граница/тень, без жёсткой чёрной рамки.
2. Шапка — одна строка `[‹] 🛒 Продукты`, не центрировано, заголовок —
   часть одного блока с кнопкой; длинные названия — перенос/аккуратная
   обрезка без разрушения layout.
3. Фон — переиспользовать существующий Home background token
   (`--main-bg-grad`, тот же, что `#scrRecords`/`#scrBudgets`), без нового
   токена/подобранного цвета; проверить light/dark.
4. Все карточки экрана — дизайн-принцип Home (переиспользовать
   `.fincard`/`.home-daycard`/`.home-tx`, не изобретать новый похожий стиль).
5. Summary-карточки (/мес, /год, за период) — стиль карточек Home; починить
   обрезание `/год` (`€4 50...`) без изменения расчётов.
6. Карточки операций — визуально ближе к Home (переиспользовать
   `.home-tx`/`.home-daycard` вместо старых `.tx`/`.daycard`), CRUD/данные
   не менять.
7. Верхние фильтры — сохранить Месяц/Год/Всё/Период и навигацию месяца,
   сделать компактнее по вертикали.
8. Даты операций — компактный заголовок дня («Ср, 19 августа» вместо
   «Среда, 19 августа 2026 г.») **только на этом экране**, год не
   дублировать (уже виден в выбранном периоде).
9. Ничего лишнего не менять — расчёты, фильтрация, данные, CRUD,
   обработчики, другие экраны — без изменений.

## Фактическая реализация

**Разметка (`index.html`).** `#catTxOverlay` переведён из модальной
`.detail-sheet` (`×`, центрированный `.detail-top`) в отдельный полноэкранный
блок `.catx-page` — тот же архитектурный приём, что `.prof-page` (TASK_021)/
`.secp-page` (TASK_023): собственный скролл, `env(safe-area-inset-*)`,
`overlay.catx-ov{align-items:flex-start;justify-content:center;background:
rgba(0,0,0,.35)}`. Кнопка «Назад» — `.catx-back`, id `catTxClose` сохранён
без изменений (обработчик закрытия `classList.remove('show')` не менялся —
тот же существующий корректный способ, что у Профиля/Безопасности). Шапка —
`.catx-nav` (flex-row, `gap:11px`): кнопка + `.catx-title` (`flex:1`, не
абсолютное центрирование), длинные названия — `-webkit-line-clamp:2` (перенос
до 2 строк, затем аккуратная обрезка, без разрушения layout — проверено
синтетическим длинным названием). Summary-блок обёрнут в **буквально**
`class="fincard catx-summary"` — переиспользование существующего Home-
компонента (background/border/radius/box-shadow), не новый похожий стиль;
добавлен только padding через scoped `.catx-summary{padding:...}`.

**Фон.** `.catx-page{background:var(--main-bg-grad)}` — тот же токен, что
`#scrRecords`/`#scrBudgets` (TASK_039), не новый подобранный цвет. Тёмная
тема не тронута отдельно: `--main-bg-grad` уже зафиксирован на
`var(--home-bg)` в `[data-theme="dark"]` (наследуется автоматически).

**Кнопка «Назад» (п.1 ТЗ).** `.catx-back` — круг 46px (в требуемом диапазоне
44–48px), `background:var(--card)` (светлый), `border:1px solid
rgba(0,0,0,.07)` (тёмная тема — `rgba(255,255,255,.10)`) + `box-shadow:
var(--fincard-shadow)` — мягкая граница и лёгкая тень **без** жёсткой чёрной
рамки (сознательно не переиспользован `.secp-back`, у которого `border:1.6px
solid var(--text)` — по описанию пользователя это и есть «жёсткая рамка»,
которую просили убрать). SVG-шеврон `‹`, `13×22px`.

**Summary-карточки и починка обрезания `/год` (п.5 ТЗ).** Причина обрезания
(`€4 50...`): `.cat-avg .ca-i` держала `white-space:nowrap;overflow:hidden;
text-overflow:ellipsis`. Убраны `nowrap`/`ellipsis` → `white-space:normal;
word-break:break-word`, добавлен адаптивный `font-size:clamp(12.5px,3.6vw,
15px)`. Расчёт (`avgM`/`avgY`/`sum`, `num()`) не тронут — проверено значением
€28 657,68, которое раньше обрезалось бы, теперь помещается полностью без
переноса на мобильной ширине 375px.

**Карточки операций (п.6 ТЗ) и компактные заголовки дня (п.8 ТЗ).** Новая
функция `catxGroupedTxHtml()` — рендерит `#catTxList`, переиспользуя
`homeTxRow()`/`.home-tx`/`.home-daycard` (тот же компонент, что на Главной,
`TASK_004`) вместо старых `.tx`/`.daycard`. **Общий** `groupedTxHtml()`
(используется «Все операции», `#allTxOverlay`) не изменён — проверено тестом
§6, что `openAllTx()` по-прежнему вызывает старую функцию. Заголовок дня —
новая `catxDayLabel()` («Ср, 19 августа», без года — год уже виден в `r.lbl`
над списком), **не** трогает `dayLabelFull()` (используется Главной/«Все
операции»/остальными экранами без изменений).

**Компактность фильтров (п.7 ТЗ).** `#catTxOverlay .seg-ie{margin:2px 0 4px}`,
`#catTxOverlay .navrow{margin:0 0 10px}` — scoped-переопределения отступов,
базовые `.seg-ie`/`.navrow` (используются другими экранами) не изменены.

**Расчёты/данные/CRUD** — не изменены: `catTxRange()`, `monthsInRange()`,
фильтрация `state.tx.filter(t=>t.type===ty&&catTxIds.includes(t.cat)&&
inAnaRange(t,r))`, `openCatTx()` (обе точки входа — Аналитика и Бюджеты),
клик по строке операции по-прежнему открывает `openSheet()` (проверено
вручную — редактор операции открылся с верными данными). Версия кэша `sw.js`
поднята `finance-v170` → `finance-v171`.

## Известные ограничения

- Реальная проверка на физическом iPhone не выполнялась в этой сессии
  (виртуальный мобильный viewport не воспроизводит реальные safe-area-
  отступы и системные жесты) — рекомендуется пользователю после публикации,
  та же практика, что в предыдущих задачах (`TASK_017`, `TASK_039` и др.).
- Инструмент клика превью (`computer`) стабильно таймаутился в этой сессии
  независимо от координат/элемента (инфраструктурная особенность окружения,
  не связана с кодом приложения) — интерактивные проверки (открытие экрана,
  клик по операции, клик «Назад») выполнены через прямой вызов функций
  приложения (`openCatTx()`, `document.getElementById(...).click()`) и
  подтверждены скриншотами/DOM-состоянием; `.catx-back`/`.home-tx` — обычные
  `<button>`/кликабельные `<div>` с реальными обработчиками, отдельного
  риска для реальных тач-/мышь-кликов это не создаёт.
