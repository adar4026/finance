# TASK_064 — Премиальная анимация градиентных волн hero

**Статус:** DONE — релиз **v2.5.0** (cache `finance-v198`) опубликован в `main` и проверен
на production (см. «Публикация»).

## Контекст

Фон пяти immersive-экранов рисует общий слой `.finance-ambient` (TASK_047/048):
WebGL-canvas `#heroCanvas` (`AF.HeroCanvas`, `js/ui/hero_canvas.js`,
TASK_054 → TASK_058 «единый рельеф LexCar: fold/layer») высотой
`var(--hero-h)`, под ним CSS-fallback из четырёх blob'ов. Палитра шейдера
приходит из CSS-токенов `--hero-gl-*` (light/dark), а не зашита в код.

Сейчас это violet/lavender гамма LexCar-происхождения (TASK_054). Волны
мелковаты и контрастны: видны границы «полос» (band), заметная светлая
диагональ, рельеф читается как декоративный эффект поверх интерфейса.

## Цель

Сохранить существующие переливающиеся волны и их механику, но довести их до
премиального уровня: сдержаннее, плавнее, глубже; фирменная сине-голубая
гамма LexMoney с деликатным бирюзовым акцентом. Не строгое разделение фона
на два цвета, а развитие текущей концепции.

## Требования

1. Волны сохраняют характер: крупные органичные формы, мягкие переходы,
   умеренная глубина, многослойность, деликатные световые переливы; без
   навязчивых контуров и резких изгибов.
2. Палитра — глубокий насыщенный синий, чистый яркий синий, мягкий
   голубой, деликатный бирюзовый акцент; цвета перетекают друг в друга,
   без резких границ между цветовыми областями и без кислотных пятен.
3. Анимация непрерывная, медленная, ненавязчивая: без скачков, мерцания,
   внезапной смены оттенков; без сброса при прокрутке; без конфликта с
   существующим единственным scroll-обработчиком `#scrollArea`.
4. Единый визуальный язык на всех пяти immersive-экранах; читаемость
   текста и показателей не ухудшается.
5. `prefers-reduced-motion` продолжает отключать анимацию (CSS-fallback).
6. Без новых обработчиков, утечек, тяжёлых свойств; один draw на кадр,
   ~30 fps, DPR ≤ 1.5 — как было.

приглушённее, волны заметно слабее светлой); по решению пользователя это

### 2. Форма волн и свет — `js/ui/hero_canvas.js`, только константы внутри `FRAG`

- `fold()`: пространственные частоты снижены ≈ на 15 %
  (`1.5/1.1 → 1.28/0.94`, шумы `0.75/1.05 → 0.62/0.88`, `1.3/1.4 → 1.10/1.18`) —
  формы крупнее и органичнее. Сильнее снижать нельзя: при частоте ≤ 1.0 ширина
  hero (≈ 375×460 CSS-px) укладывает меньше четверти периода, и кадр вырождается
  в почти ровную заливку — проверено в превью и зафиксировано в комментарии.
- Вклад мелкого шума `n2`: `0.06 → 0.035` — меньше ряби.
- `layer()`: амплитуда псевдонормали `0.30 → 0.24` (рельеф без резких изгибов);
  обе рампы `band` удлинены (`−0.35 → −0.55`, `1.25 → 1.45`) — границы цветовых
  областей не читаются как контур, но покрытие осталось частичным (при полном
  покрытии три слоя усредняются в ровную заливку — тоже проверено в превью);
  контраст diffuse `0.28 → 0.26`; тень к `u_deep` `0.26 → 0.30` (глубина вместо
  яркости); specular `pow 12 → 8` и несёт бирюзовый подтон
  (`mix(vec3(1.0), u_c3, 0.30)`) вместо чистого белого.
- `main()`: база — `mix(u_top, u_bot, smoothstep(0.0, 1.0, uv.y))` вместо
  линейной `uv.y`; нижний fade начинается выше (`0.58 → 0.56`).

### 3. Анимация

Темп замедлен: дрейф `0.05 → 0.034`, фаза синусоиды `0.14 → 0.10`, дрейф шумов

`t` по отрисованным кадрам с clamp delta, один `drawArrays` на кадр, 30 fps,
DPR ≤ 1.5, пауза по `document.hidden` и `IntersectionObserver`.

## Известные ограничения

1. **Мелкие подписи `--muted2`** («2 операции», «за месяц», 10.5 px) дают в худшей
   точке hero контраст ≈ 1.15 : 1 (светлая тема: было 1.18, стало 1.15 — ухудшение на
   0.03; тёмная: 1.21 → 1.19). Это свойство фона immersive-экранов (TASK_047), задача
   TASK_064 его не исправляет. Исправление требует смены цвета или подложки подписей —
   отдельная задача.
2. **CSS-fallback (blob'ы TASK_047)** не менялся: он виден только без WebGL, при
   `prefers-reduced-motion` и при потере контекста. Его интенсивность и тон отличаются
   от нового WebGL-слоя; это не измерялось отдельно и отдельной задачей не разбиралось.
3. **Тёмная тема** приглушена (см. «Палитра»); волны в ней заметно слабее светлой.
   Принято пользователем без дальнейших изменений.
4. **`prefers-reduced-motion`** в браузерной панели не эмулировался: путь не менялся
   задачей и покрыт юнит-тестами `tests/home_hero_webgl.test.js` §6/§7
   (`mount() → false`, WebGL-контекст не запрашивается).
5. **Ошибки в консоли** — только CORS от `static.cloudflareinsights.com` (beacon в
   `index.html`, строка 8435, есть в `HEAD` до задачи): на `localhost` не проходит
   preflight. Ошибок приложения нет.
6. **Проверка на реальном iPhone / установленной PWA** в рамках Dev Preview не
   выполнялась; проверка опубликованной версии — в разделе «Публикация».
7. **Теги релизов.** В репозитории есть только `v1.0` и `v1.0.0`; ссылки версий 2.x в
   футере `CHANGELOG.md` не соответствуют существующим тегам (это было до TASK_064).
