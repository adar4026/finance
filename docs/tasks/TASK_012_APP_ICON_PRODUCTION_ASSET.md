## Что фактически сделано

1. Подтверждено: `IMG_2662.jpg` найден в корне репозитория,
   602×619 px, JPEG, встроенный ICC-профиль Display P3, EXIF
   `description: Screenshot`.
2. Обработка (Python/Pillow):
   - цветовой профиль переведён из встроенного Display P3 в sRGB
     (`ImageCms.profileToProfile`);
   - кадр 602×619 дополнен белыми полями до квадрата 619×619
     (по 8/9 px слева/справа, без единого пикселя обрезки —
     `off_x=8, off_y=0`), композиция и пропорции не менялись;
   - из полученного мастер-изображения рендерены (Lanczos-ресайз +
     мягкий `UnsharpMask` для компенсации смягчения при
     JPEG-происхождении и downscale): `icon-512.png` (512×512),
     `icon-192.png` (192×192), `apple-touch-icon.png` (180×180),
     `favicon-32.png` (32×32).
3. Все 4 файла установлены в корень репозитория под теми же именами,
   что уже были прописаны в `manifest.json`/`index.html`/`sw.js` — правка
   этих ссылок не потребовалась (пути и размеры совпали без изменений).
4. `sw.js`: версия кэша `finance-v152` → `finance-v153` (имена
   закэшированных иконок не изменились, но их байты изменились —
   бамп версии нужен, чтобы уже установленные PWA не отдавали иконку из
   старого кэша; согласуется с практикой всех предыдущих задач проекта).
5. `icon.svg` — не тронут (остался удалённым, как было до начала задачи);
   подтверждено `grep`, что нигде не используется кодом — вне границ.

## Известные ограничения

- Источник (`IMG_2662.jpg`) — растровый скриншот 602×619, а не векторный
  оригинал; итоговые PNG получены масштабированием этого растра, а не
  перерисовкой из векторных данных. Для 512×512 это увеличение вниз
  (без потери детализации), для 32×32 — сильное уменьшение, поэтому
  тончайшие детали (кончик стрелки) на favicon неизбежно менее чётки,
  чем на 512px варианте — это физический предел растрового источника,
  не артефакт обработки.
- В рабочем дереве до начала этой задачи уже была незакоммиченная
  незапланированная правка `.claude/launch.json` и удаление `icon.svg` —
  зафиксировано выше, не является результатом этой задачи и не
  затронуто ею.
