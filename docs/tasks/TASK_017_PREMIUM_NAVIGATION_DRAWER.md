## 1. Контекст

Боковое меню (drawer, `#drawerOverlay`/`.drawer`) функционально работает
(открывается по аватару, ведёт на все экраны), но визуально оформлено как
обычный плоский список строк на белом фоне с emoji-иконками и жирным
градиентным header'ом — не соответствует премиальному визуальному языку
остальных недавно переработанных экранов (`TASK_003`/`TASK_014`).
Пользователь предоставил референс-макет «Концепция 2 — Apple Wallet /
Liquid Glass» и подробное ТЗ (см. промпт пользователя) на полную
визуальную переработку drawer'а.

## 2. Цель

Переработать внешний вид Navigation Drawer в премиальном стиле,
вдохновлённом Apple Wallet / Apple Settings / iOS HIG / Liquid Glass, не
копируя интерфейсы буквально — только заимствуя дизайн-принципы.
Только визуальная переработка: без изменений архитектуры, навигации,
бизнес-логики, существующих функций и без новых экранов.

## 3. Границы

**Включено:**

- Полная визуальная переработка `#drawerOverlay`/`.drawer` (CSS + разметка
  этого блока в `index.html`) и связанного JS рендеринга
  (`openDrawer()`/`closeDrawer()`/`renderDrawerCap()`/`renderReleaseInfo()`).
- Новый header-«кошелёк» (градиент, скругления, аватар/имя/подпись/chevron,
  единая кнопка → `openProfile()`, как и раньше).
- Группировка пунктов меню в белые карточки с заголовками групп.
- Единый набор SVG-иконок (стиль SF Symbols) вместо emoji, свой цвет на
  каждую иконку.
- Редизайн badge уведомлений (только внутри drawer — `.prof-badge` вне
  drawer, используемый экраном профиля, не трогается).
- Тонкие разделители (`rgba(0,0,0,.06)`).
- Переработанный footer (имя приложения + версия, без даты релиза).
- Анимации открытия: слайд drawer, fade-in header, последовательное
  появление карточек — короткие и ненавязчивые.
- Blur + затемнение + лёгкое уменьшение масштаба (~0.98) главного экрана
  позади drawer при открытии.
- Bump версии кэша `sw.js`.

**Не включено (запрещено трогать):**

- Архитектура приложения, навигация между экранами, бизнес-логика.
- Любые экраны, открываемые из drawer (Категории/Цели/Календарь/
  Регулярные платежи/Финансовое здоровье/Статистика/Безопасность/
  Экспорт/Все настройки) — только точки входа в drawer, не содержимое
  этих экранов.
- Переключение темы (`toggleTheme()`) — поведение и подпись
  («Тёмная тема»/«Светлая тема») не меняются, меняется только иконка и
  визуальный контейнер строки.
- `.prof-row`/`.prof-badge` на экране профиля/«Все настройки» — общий
  CSS-класс `.prof-badge` не правится, у бейджа drawer используется
  отдельный класс.
- Модель данных, `AF.Store`, `SCHEMA_VERSION`, любые сервисы `js/services/*`.
- Карточка общего капитала (`drawer-cap`, баланс + спарклайн) — функция
  сохраняется (не в явном списке групп ТЗ, но это существующая функция,
  которую нельзя удалять по правилам границ), только визуально
  подстраивается под новый стиль (радиус, тень, отступы).

## 4. Требования (из промпта пользователя)

1. Drawer: светло-серый системный фон, крупные скругления, мягкие тени,
   настоящий blur позади меню, плавное появление. Ширина ~86% экрана, не
   закрывает главный экран полностью.
2. Background blur: во время открытия — затемнение + blur главного экрана,
   опционально лёгкое уменьшение масштаба (~0.98).
3. Header: карточка в духе Apple Wallet — сиренево-голубой градиент, лёгкий
   glass, крупные скругления (~24px), аватар/имя/подпись, chevron справа,
   весь header — одна кнопка, без вспомогательного текста.
4. Группы: карточки «Планирование» / «Аналитика» / «Приложение» вместо
   одного списка.
5. Типографика: заголовки групп ~12px серый uppercase; пункты меню 17px
   Semibold (не Bold).
6. Иконки: единый набор SVG (стиль SF Symbols) вместо emoji, свой цвет на
   каждую.
7. Badge уведомлений: скругление, мягкая тень, аккуратные отступы.
8. Разделители: тонкие, `rgba(0,0,0,.06)`.
9. Нижняя часть: убрать текущую толстую полосу/старый footer, оставить
   компактный footer (имя + версия), без «Released …».
10. Анимации: быстрые и ненавязчивые (slide, fade, staggered появление
    карточек).
11. Не менять архитектуру/навигацию/бизнес-логику/функции, не добавлять
    экраны.
12. Проверить на iPhone Safari PWA, safe-area, светлую тему, плавность,
    отсутствие layout shift и переполнения текста.

## 6. Реализация

### 6.1. Изменённые файлы

- `index.html`:
  - CSS-блок «Боковая выезжающая панель (drawer)» переписан полностью:
    светло-серый системный фон (`var(--home-bg)`), скругление правого края
    (`0 28px 28px 0`), мягкая тень, ширина 86% (max 360px); усилен
    backdrop-filter затемнения (`.overlay.drawer-ov`); добавлены правила
    `.app,.nav{transition:...}` + `body.drawer-open .app,body.drawer-open
    .nav{filter:blur(6px) brightness(.92);transform:scale(.98)}` для
    затемнения/blur/уменьшения масштаба главного экрана позади drawer;
    новый header-«кошелёк» (`.drawer-head` — сиренево-голубой градиент,
    скругление 24px, glass, fade-in анимация); группы (`.drawer-group`,
    `.drawer-group-title`, `.drawer-card`) с последовательным появлением
    через `animation-delay:calc(...+ var(--i) * .05s)`; строки
    (`.drawer-row`) — 17px/Semibold, цветные иконки-чипы `.dr-ic`
    (29×29px, свой `--ic` цвет на каждую), `.dr-chev` (тонкий шеврон
    вместо текстового `›`); badge — новый класс `.dr-badge` (не
    `.prof-badge` — тот общий класс профиля не тронут); разделители
    `.drawer-sep{background:rgba(0,0,0,.06)}` (тёмная тема —
    `rgba(255,255,255,.08)`); карточка капитала (`.drawer-cap`) — радиус
    увеличен, тень смягчена, встроена в общий ритм появления карточек;
    footer (`.drawer-footer`) — компактный, без строки даты релиза.
  - Разметка `#drawerOverlay`/`.drawer` перестроена: `.drawer-scroll`
    (flex-колонка) → header-кнопка (аватар/имя/подпись «Личный
    профиль»/chevron, без вспомогательного текста) → три
    `.drawer-group` («Планирование»: Категории/Цели/Календарь/
    Регулярные платежи; «Аналитика»: Финансовое здоровье/Статистика;
    «Приложение»: Уведомления/Безопасность/Оформление/Экспорт и
    копии/Все настройки) → карточка капитала → footer. Emoji заменены
    на 11 inline SVG-иконок в едином stroke-based стиле (тот же приём,
    что уже используют иконки нижней навигации): folder, target-rings,
    calendar, repeat, heart, bar-chart (переиспользована иконка
    «Аналитика» нижней навигации), bell, shield, paintpalette, export
    (стрелка из лотка), gear — у каждой свой цвет (`--ic`).
  - JS: `openDrawer()` — убрано `textContent` на emoji (иконка теперь
    статичный SVG-чип), добавлен `document.body.classList.add(
    'drawer-open')`; `closeDrawer()` — добавлено
    `document.body.classList.remove('drawer-open')`; клик по `#drTheme` —
    только обновляет `#drThemeLbl` (без перезаписи иконки); Escape-
    обработчик — добавлено снятие `drawer-open` с `body` (иначе фон
    остался бы размытым при закрытии по Esc, минуя `closeDrawer()`);
    `renderReleaseInfo()` — убрана строка `Released ${releaseDate}`.
- `sw.js` — `CACHE`: `finance-v158` → `finance-v159` (новых файлов в
  `ASSETS` нет — новых JS/CSS-файлов задача не добавляла).

### 6.2. Обоснование дизайн-решений

- **Карточка капитала оставлена** (не входит в явный список групп ТЗ, но
  промпт помечен как «Например:», а границы AGENTS.md запрещают удалять
  существующие функции) — визуально подстроена под новый стиль (радиус
  22px, мягкая тень), расположена отдельной картой после групп меню и
  перед footer.
- **«Оформление»** — существующая строка переключения темы (`#drTheme`,
  `toggleTheme()`) сохранена без изменения поведения (переключает тему
  сразу, drawer не закрывается — как и раньше); визуально переоформлена
  под новую иконку (paintpalette) и подпись динамически показывает
  текущий режим («Тёмная тема»/«Светлая тема»), как и до задачи — просто
  без emoji в тексте (эмодзи был текстовым префиксом подписи, теперь его
  роль полностью выполняет цветная SVG-иконка).
  Отдельного экрана «Оформление» не создавалось — новых экранов задача
  не добавляет.
- **Иконка «Экспорт и копии»** — в списке ТЗ (bell/calendar/chart/target/
  shield/gear/heart/folder/repeat/paintpalette) нет отдельной иконки для
  экспорта; список помечен как пример («Например:»), поэтому добавлена
  дополнительная SVG-иконка в том же stroke-based стиле (стрелка вверх из
  лотка — «поделиться/экспорт»), не нарушающая единообразие набора.
- **Badge** — вынесен в собственный класс `.dr-badge`, чтобы не менять
  общий `.prof-badge`, используемый экраном профиля (`#profNotifBadge`) —
  изоляция стилей строго в границах drawer.

## 8. Известные ограничения

- Реальная проверка на iPhone (Safari standalone PWA) не выполнена —
  инструмент iOS-симулятора недоступен в этой сессии (см. §7). CSS уже
  использует `env(safe-area-inset-top/bottom)` в header/footer drawer
  (тот же приём, что был в исходной версии), но визуальное подтверждение
  на реальном устройстве остаётся открытым пунктом.
- Прокрутка `.drawer-scroll` не сбрасывается к началу при повторном
  открытии drawer (сохраняет позицию скролла с прошлого раза) — то же
  поведение было и до этой задачи (обычный `overflow-y:auto` на
  повторно показываемом элементе), не регрессия и не входит в границы
  ТЗ.
- Иконка «Экспорт и копии» — не из буквального списка ТЗ (см. §6.2),
  добавлена дополнительно для полноты единого набора.
