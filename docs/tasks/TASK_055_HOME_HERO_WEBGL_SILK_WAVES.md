# TASK_055 — Главная: WebGL-hero — от glossy-бликов к текучим шёлковым волнам

**Статус:** DONE (опубликовано)

## Контекст

`TASK_054` перенесла в Finance WebGL-фон hero из Lexcar (шейдер 1-в-1,
палитра — violet/lavender из токенов `--hero-gl-*`). Технически всё
работает (lifecycle, pause/resume, fallback, DPR cap, 30 fps), но визуально
пользователь отмечает: слишком много ярких белых пятен-бликов (specular
hotspots, `pow(…, 12)` + чисто белый `vec3(1.0)`), которые заметно «ездят»
по поверхности; рисунок дробный/пятнистый. Желаемый характер — Revolut-
подобный liquid silk: 2–4 крупные текучие ленты, длинные диагональные
переливы, растянутые молочно-лавандовые highlights вместо точечных белых,
меньший контраст light/shadow, медленное протекание слоёв через экран.

## Цель

Изменить только визуальный характер (shader look, lighting, форма/тайминг
волн, отклик палитры), сохранив всю инфраструктуру `TASK_054`.

## Требования

1. Освещение: specular hotspot ослаблен и растянут (низкая степень
   `pow`, вклад через молочно-лавандовый `u_c3`, а не `vec3(1.0)`);
   контраст diffuse/shadow снижен.
2. Форма: 3 крупных вытянутых волновых слоя в собственной повёрнутой
   системе координат (длинные диагональные ленты, изгиб — низкочастотным
   шумом, растянутым вдоль ленты); мелкомасштабный шум сведён к минимуму.
3. Движение: гребни протекают через экран (фаза по времени), слои
   смещаются друг относительно друга с разными углами/скоростями/seed;
   непрерывное время — без видимого цикла.
4. Палитра: violet / purple / lavender / soft lilac; highlights —
   молочно-лавандовые; тени — глубокий purple; без cyan/teal.
5. Производительность не хуже `TASK_054`: три вызова height-field на слой
   (h, hx, hy), два `snoise` на вызов — как было; ~30 fps, один draw.

## Фактический результат

**Реализовано 2026-09-17, визуальный результат подтверждён пользователем
(итерация 4 — финальная, больше не меняется).**

### Итерации

1. Первая: `fold` → `wave`/`silk` (повёрнутые ленты, широкий sheen вместо
   белого specular) — пользователь: белых пятен нет, но геометрия не
   читается.
2. Вторая (по референсу Revolut): ленты в одном направлении + продольные
   `streak`-дорожки, насыщенная база — пользователь: видны переливы света,
   но не сами объёмные волны. **Streak убран.**
3. Третья: переписана геометрия — каждая волна отдельная крупная форма,
   свет считается от суммарного рельефа. Пользователь подтвердил геометрию.
4. Четвёртая (финальная): только интервалы `per` уменьшены для плотной
   композиции (≥2 волны в кадре); проверено тремя кадрами 0/9/18 с на
   390 px.

### Изменения (только look)

`js/ui/hero_canvas.js` — diff только внутри GLSL `FRAG` и `FALLBACK_PALETTE`
(JS-обвязка, uniforms API, VERT, simplex noise — без изменений):

- **Как формируется одна волна** — `waveShape(p, t, ang, speed, per, w0,
  seed)` (`hero_canvas.js:96-110`):
  - координаты поворачиваются под `ang` (`mat2 rot`): x вдоль гребня, y
    поперёк; поперечная координата `y = q.y − t·speed` — волна входит с
    края, проходит экран и уходит;
  - **кривизна** (`:100-101`): центр-линия гребня `c(x) = 0.30·sin(0.9x +
    φ + 0.045t) + 0.42·snoise(0.55x + seed, 0.035t)` — широкая дуга +
    локальное отклонение; обе компоненты эволюционируют по t, поэтому
    следующий проход волны имеет другую форму (нет видимого loop);
  - **ширина** (`:103`): `w = w0·(1 + 0.40·snoise(0.7x + seed, 0.025t))` —
    меняется вдоль гребня («закручивается»);
  - поперечное расстояние `d = (per/π)·sin(π(y−c)/per)/w` —
    периодизировано гладко (около гребня ≈ линейно, вдали ограничено), шва
    между соседними волнами нет;
  - **гребень** (`:107`): `crest = exp(−|d|^1.5)` — заострённый верх;
  - **впадина** (`:108-109`): `valley = exp(−0.9(d−1.6)²)`, профиль
    `crest − 0.55·valley` — мягкая ложбина на одном склоне (асимметрия).
- **Три волны** (`relief()`, `:115-119`): A — амплитуда 1.0, угол −0.78,
  скорость 0.055, интервал 1.6, ширина 0.17 (~35 % ширины hero); B — 0.85,
  −0.50, 0.042, 1.8, 0.24 (~50 %); C — вторичная 0.45, −1.05, 0.070, 1.4,
  0.13. Интервалы `per` 2.2/2.7/1.9 → 1.6/1.8/1.4 (итерация 4, по
  замечанию пользователя): при ширине hero ≈1.3 ед. в большинстве фаз
  одновременно видны ≥2 крупные волны, периодически третья слабая — без
  пустых фаз и без превращения в частую полосатую структуру (масштаб,
  профиль crest/valley, кривизна и свет не менялись). Базовое направление согласовано (↘), у каждой свои кривизна/
  ширина/скорость/фаза. `relief()` возвращает **сумму** — в местах
  пересечения гребни складываются, волны взаимодействуют.
- **Свет от формы** (`main()`, `:130-153`): нормаль — конечные разности
  суммарного рельефа (сила 0.50); `lit`/`shadow` — склон к свету/от света
  относительно плоскости (плоский фон не тонируется); `valley =
  smoothstep(0, −0.4, H)` — затемнение ложбины; `rim = (1−N.z)^1.3` —
  кромка на крутых склонах; `spec = pow(·,8)` — highlight гребня. Порядок:
  база → окраска каждой волны по её гребню (`clamp(h_i)·alpha_i`) →
  `×(1+0.45·lit)` → `mix(u_deep, 0.65·shadow + 0.25·valley)` →
  `mix(u_c3, (0.9·spec + 0.35·rim)·u_light)` → нижний fade (прежний).

`index.html` — только значения токенов: `--hero-gl-top` #e6e1fb → #c9bff9
(dark #161331 → #1f1a45); `--hero-gl-c3` #f4f1ff → #e9e3ff (dark #cfc6ff
→ #b8abf2); `--hero-gl-alpha` .46 .40 .52 → .44 .40 .36 (dark .34 .24 .16
→ .34 .26 .16); `--hero-gl-light` .75 → .62 (dark .22 → .30).

`sw.js` — `finance-v186` → `finance-v187`.

`tests/home_hero_webgl.test.js` — §5 переписан под новую геометрию
(waveShape/relief, crest/valley/кривизна/ширина, три волны с
собственными параметрами, 2 доминирующие + 1 вторичная, свет от
суммарного рельефа, нет белого specular и streak; VERT и snoise
по-прежнему 1-в-1 с Lexcar). Всего 130 проверок.

### Grayscale-проверка геометрии

В preview палитра временно подменена серой (`--hero-gl-top/bot/c1/c2` =
#9a9a9a, alpha 0, `c3` белый, `deep` чёрный) через инжект `<style>` +
переключение `data-theme` (MutationObserver перечитал uniforms). Без цвета
рельеф читается как объёмная волна: изогнутый гребень со светлой кромкой,
теневой склон, тёмная ложбина между волнами. Стиль удалён, палитра
восстановлена тем же путём.

### Оценка

- White hotspots: нет — белого `vec3(1.0)` в шейдере нет, highlight
  гребня и кромка — `u_c3` (молочная лаванда).
- Волны: 2 доминирующие + 1 вторичная крупные объёмные формы с гребнем,
  впадиной, кривизной и переменной шириной; протекают через экран,
  складываются при пересечении; без мелких полосок и решётки.
- Производительность: та же по бюджету — 3 вызова `relief` (h, hx, hy)
  × 3 волны × 2 `snoise` = 18 `snoise` на фрагмент (в TASK_054 было 18),
  один draw; замер 52 draw за 2 с (≈25 fps, throttle прежний); DPR cap,
  lifecycle не тронуты.
