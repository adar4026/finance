`TASK_020` (Apple-редизайн экрана «Счета») завершена, закоммичена

Следующий запрошенный пользователем этап — переработка личного профиля:

пользователю (фото + имя) плюс единственную секцию «Защита» с пунктом
«Безопасность», перенесённым из боковой шторки.

## 3. Найденные существующие компоненты и архитектура (переиспользуются)

- **Профиль** — `#profOverlay` (`.overlay` + `.modal`, нижняя шторка),
  открывается `openProfile()` из карточки-«кошелька» боковой шторки
  (`#drawerHead`, `TASK_017`) и из аватара шапки. Содержит `.prof-head`
  (аватар `#profAvatar` + `<input id="profName">`) и 10 строк
  `.prof-row`: `#changePhoto`, `#profNotif`, `#profGoals`,
  `#profCalendar`, `#profHealth`, `#profStats`, `#profSecurity`,
  `#profTheme`, `#profExport`, `#profMore`.
- **Механизм смены фото уже существует и переиспользуется целиком**:
  `#changePhoto` → `$('#photoInput').click()` → `onchange` →
  `FileReader` → `<canvas>` 256×256 (центральный квадратный кроп,
  JPEG q=0.85) → `state.avatar` → `save()` + `renderHeader()`. Хелперы
  `avatarStyle()`/`avatarInner()` (`index.html:2552–2553`) — общие для
  шапки, боковой шторки и профиля.
- **Имя** — `state.profileName`, `oninput` пишет в state, `onchange`
  сохраняет и обновляет шапку/инициал аватара. Формат хранения не
  меняется.
- **Безопасность** — `#securityOverlay` (`.detail-sheet`, отдельный
  полноэкранный слой) + `openSecurity()`/`renderSecurity()` (PIN,
  скрытие сумм). В боковой шторке — пункт `#drSecurity` (группа
  «Приложение»), в профиле — строка `#profSecurity`. Обе вызывают одну и
  ту же `openSecurity()`.
- **Стиль-ориентир (Главная)** — `var(--home-bg)` (светло-серый фон),
  `var(--card)` + `border-radius:20–22px` + `var(--fincard-shadow)`
  (белые карточки), тонкие inset-разделители `rgba(0,0,0,.06)` /
  `rgba(255,255,255,.08)` в тёмной теме. Стиль строки меню с цветной
  SVG-иконкой в скруглённом чипе — `.drawer-row`/`.dr-ic`/`.dr-chev`
  (`TASK_017`); иконка щита для «Безопасности» уже нарисована в
  `#drSecurity` (`--ic:#30b0c7`) — переиспользуется буквально при
  переносе. Паттерн полноэкранного слоя — `.overlay` +
  `align-items:flex-start` + контейнер на всю высоту (как
  `#securityOverlay`/`#catMgrOverlay`).

## 4. Цель

Превратить личный профиль в отдельный чистый экран уровня Главной:
светло-серый фон, Apple-кнопка «Назад» и заголовок «Профиль», белая
карточка с крупным круглым фото и редактируемым именем, аккуратная
возможность сменить фото и единственная секция «Защита» с пунктом
«Безопасность». Все общие настройки остаются в боковой шторке; пункт
«Безопасность» из боковой шторки переносится (а не дублируется) в
профиль.

## 5. Границы

**Включено:**

1. Боковая шторка: удалить пункт «Безопасность» (`#drSecurity` +
   соседний `.drawer-sep` + обработчик `$('#drSecurity').onclick`).
   Остальные пункты, группы, оформление и анимации `TASK_017` — не
   трогать. Карточка-«кошелёк» `#drawerHead` уже открывает профиль —
   поведение сохраняется без изменений.
2. `#profOverlay` переоформляется из нижней модальной шторки
   (`.modal`) в полноэкранный экран (`.prof-page`): фон
   `var(--home-bg)`, шапка с Apple-кнопкой «Назад» (SVG-шеврон + текст,
   системный синий `var(--nav-blue)`) слева и заголовком «Профиль».
3. Верхняя белая карточка: крупный круглый аватар (96px, существующие
   `avatarStyle()`/`avatarInner()`), кнопка-камера на аватаре, поле
   ввода имени (`#profName`, `state.profileName`, placeholder `A-Lex`),
   разделитель и строка «Сменить фото» с иконкой камеры и шевроном.
   Оба элемента (кнопка-камера и строка) вызывают **существующий**
   `#photoInput` — механизм выбора/сжатия/сохранения фото не изменяется.
4. Секция «Защита» — заголовок группы (uppercase, как
   `.drawer-group-title`) + белая карточка с единственной строкой
   «Безопасность» (иконка-щит из `#drSecurity`, шеврон) →
   существующий `openSecurity()`.
5. Удалить из профиля строки `#profNotif` (+ `#profNotifBadge`),
   `#profGoals`, `#profCalendar`, `#profHealth`, `#profStats`,
   `#profTheme` (+ `#profThemeLbl`), `#profExport`, `#profMore` вместе
   с их обработчиками. Целевые экраны (уведомления, цели, календарь,
   финздоровье, статистика, тема, экспорт, все настройки) **не
   удаляются** — они остаются доступны из боковой шторки
   (`#drNotif`/`#drGoals`/`#drCalendar`/`#drHealth`/`#drStats`/
   `#drTheme`/`#drExport`/`#drMore`).
6. `openSecurity()` больше не закрывает профиль — экран безопасности
   открывается поверх, и по «×» пользователь возвращается на экран
   профиля (требование «возврат назад»).
7. Bump версии кэша `sw.js`: `finance-v163` → `finance-v164`.
8. Новый тестовый файл `tests/profile_screen.test.js` — статические
   проверки `index.html`/`sw.js` (по образцу `tests/analytics_screen.test.js`,

**Не включено:**

  не изменяются.
- Формат `state.profileName` и его синхронизация с шапкой/боковой

- Экран «Безопасность» (`#securityOverlay`, `renderSecurity()`, PIN,

- Остальные экраны и общие классы (`.modal`, `.detail-sheet`,
