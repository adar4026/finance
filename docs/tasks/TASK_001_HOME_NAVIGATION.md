# TASK_001 — Home Navigation

- **Номер:** TASK_001
- **Название:** Home Navigation
- **Статус:** DONE
- **Тип:** ретроспективно оформленная завершённая задача

> Реализация была выполнена **до** внедрения системы TASK. Этот файл создан
> ретроспективно на основании кода, Git-истории, проведённых проверок и
> опубликованной версии приложения — не как план новой работы.

## Цель

Обновление верхней панели (шапки) и нижней навигации главного экрана
A-Lex Finance по референсу Ministry.

## Фактический результат

### Верхняя панель

- Реализована обновлённая верхняя панель: аватар → поиск → аналитика.
- Реализовано поведение collapsing/sticky header — закреплённой остаётся
  только верхняя строка (`.topbar`), период и навигация по месяцам живут в
  `.subhead` обычным потоком и естественно уходят при прокрутке.
- Сохранены существующие экраны, маршруты и бизнес-логика приложения.

### Нижняя навигация

- Создана высокая белая плавающая капсула (`--navh`, светлый `--card` фон).
- Сохранены пять разделов: «Главная», «Аналитика», «Добавить», «Счета», «Бюджеты».
- Центральная кнопка «+» оформлена отдельным синим кругом (токены
  `--nav-blue` / `--nav-blue2` / `--nav-blue-soft`, отдельно от фирменного
  фиолетового `--accent`).
- Текстовый знак «+» заменён симметричным белым inline-SVG крестом.
- Размер кнопки — 60×60 px.
- Выступ над капсулой — приблизительно 15 px.
- Расстояние до подписи «Добавить» — приблизительно 11 px.
- Активная вкладка выделяется синим цветом (`--nav-active-bg`).
- Неактивные подписи и иконки — `var(--text)`, font-weight 700, для
  достаточной контрастности в обеих темах.
- Сохранены существующие маршруты (`data-s="scrRecords|scrCharts|scrAccounts|scrBudgets"`).
- Сохранён обработчик открытия формы добавления операции (`#addBtn`).
- Учтены мобильные размеры и нижняя safe area:
  `bottom:max(6px, env(safe-area-inset-bottom))`.
- Кнопка «+» не перекрывает соседние вкладки.

### Примечание о финальном коммите

Изначально в качестве финального коммита задачи ориентировочно назывался
`2649700`. Проверка `sw.js`, фактически отдаваемого production
(`CACHE = 'finance-v138'`), показала, что опубликованная версия
соответствует более позднему коммиту `126943a` — двум дополнительным
фиксам позиции капсулы под safe-area на реальном iPhone (`bcb0575`,
`126943a`), которые являются прямым продолжением той же работы над
нижней навигацией, а не отдельной темой. Поэтому именно `126943a`
зафиксирован как финальный стабильный коммит TASK_001.

**Финальный стабильный коммит приложения для TASK_001:**
`126943afd479d29d8e9fe6815c67c305f2b89739`
