## Контекст запроса

Пользователь прислал референс-скриншот: круглая кнопка с тонкой
чёрной обводкой (outline-круг) и шевроном `‹` внутри — в стиле стандартной
кнопки «Назад» iOS/Apple. Запрошено реализовать именно такую кнопку для
переключения «на месяц назад / вперёд» — это существующие стрелки
`#fcMonthPrev`/`#fcMonthNext` (`.month-switch .m-arrow`) над финансовой
карточкой на Главной.

## Цель

Заменить плоские текстовые стрелки (`‹`/`›`, без фона и рамки) в
переключателе месяца финансовой карточки на круглые кнопки с тонкой
обводкой и векторным шевроном внутри — по референсу пользователя.

## Границы работы

- Затронуть **только** `#fcMonthPrev`/`#fcMonthNext` (кнопки внутри
  `#fcMonthSwitch`) и CSS-класс `.month-switch .m-arrow` в `index.html`.
- Не менять остальную часть финансовой карточки (`#finCard`, `.fincard`,
  `.fc-*`, `renderFinanceCard()`), сам список операций Главной
  (`TASK_004`), переключатель периодов День/Неделя/Месяц/Год/Период,
  нижнюю навигацию.
- Не менять обработчики кликов (`$('#fcMonthPrev').onclick`/
  `$('#fcMonthNext').onclick`, `shiftPeriod`), логику
  disabled/visibility/aria-label (`renderFinanceCard()`,
  строки ~2170–2183) — только заменить текстовый глиф на SVG-шеврон
  внутри тех же кнопок и стилизовать сами кнопки.

## Требования

1. Кнопка — круг с тонкой обводкой (`border`, не заливка), фон прозрачный/
   основной фон карточки.
2. Внутри — векторный шеврон (`<`/`>`), а не текстовый символ, для чёткой
   отрисовки на любом масштабе.
3. Должна корректно смотреться в светлой и тёмной теме без отдельных
   тёмных/светлых цветов, зашитых напрямую (через существующие
   CSS-переменные).
4. Существующее поведение — disabled-состояние (прозрачность, no-pointer-
   events), скрытие в custom-периоде, aria-label, обработчики клика —
   без изменений.

## Критерии готовности

- Визуально соответствует референсу: круглая обводка + шеврон.
- Клик по кнопке по-прежнему переключает месяц (`shiftPeriod`), disabled-
  кнопка (следующий месяц = текущий) не кликабельна.
- Светлая и тёмная тема — корректный контраст без правок.
- Нет ошибок в консоли.

## План проверок

1. Синтаксическая проверка инлайн-скрипта.
2. Визуальная проверка в браузере предпросмотра (светлая/тёмная тема).
3. Клик по кнопке «назад»/«вперёд» — проверка смены месяца и данных
   карточки/списка.
4. Проверка консоли на ошибки.

## Фактический результат

### Реализация

- `index.html`:
  - Разметка: `‹`/`›` в `#fcMonthPrev`/`#fcMonthNext` заменены на inline
    SVG-шевроны (`viewBox="0 0 24 24"`, `<path d="M15 6l-6 6 6 6"/>` для
    «назад», `<path d="M9 6l6 6-6 6"/>` для «вперёд» — тот же паттерн
    иконок, что и в нижней навигации).
  - CSS `.month-switch .m-arrow`: `border:none;background:none` →
    `border:1.6px solid var(--text);border-radius:12px` →
    `border-radius:50%` (круг), размер `44px`→`38px`; добавлено правило
    `.month-switch .m-arrow svg{width:17px;height:17px;stroke:currentColor;
    fill:none;stroke-width:2.3;...}`. Использован существующий токен
    `var(--text)` для цвета обводки/иконки — автоматически адаптируется
    под тему (тёмная обводка на светлом фоне / светлая на тёмном), без
    новых цветовых констант.
  - Не тронуты: `renderFinanceCard()` (disabled/visibility/aria-label
    логика), обработчики `onclick`, остальная разметка/CSS финансовой
    карточки и список операций (`TASK_004`).
- `sw.js`: версия кэша поднята `finance-v145` → `finance-v146`.
