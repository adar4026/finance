## Контекст запроса

Пользователь прислал референс-скриншот: круглая кнопка с тонкой
чёрной обводкой (outline-круг) и шевроном `‹` внутри — в стиле стандартной
кнопки «Назад» iOS/Apple. Запрошено реализовать именно такую кнопку для
переключения «на месяц назад / вперёд» — это существующие стрелки
`#fcMonthPrev`/`#fcMonthNext` (`.month-switch .m-arrow`) над финансовой
карточкой на Главной.

## Цель

Заменить плоские текстовые стрелки (`‹`/`›`, без фона и рамки) в
переключателе месяца финансовой карточки на круглые кнопки с тонкой
обводкой и векторным шевроном внутри — по референсу пользователя.

## Границы работы

- Затронуть **только** `#fcMonthPrev`/`#fcMonthNext` (кнопки внутри
  `#fcMonthSwitch`) и CSS-класс `.month-switch .m-arrow` в `index.html`.
- Не менять остальную часть финансовой карточки (`#finCard`, `.fincard`,
  `.fc-*`, `renderFinanceCard()`), сам список операций Главной
  (`TASK_004`), переключатель периодов День/Неделя/Месяц/Год/Период,
  нижнюю навигацию.
- Не менять обработчики кликов (`$('#fcMonthPrev').onclick`/
  `$('#fcMonthNext').onclick`, `shiftPeriod`), логику
  disabled/visibility/aria-label (`renderFinanceCard()`,
  строки ~2170–2183) — только заменить текстовый глиф на SVG-шеврон
  внутри тех же кнопок и стилизовать сами кнопки.

## Требования

1. Кнопка — круг с тонкой обводкой (`border`, не заливка), фон прозрачный/
   основной фон карточки.
2. Внутри — векторный шеврон (`<`/`>`), а не текстовый символ, для чёткой
   отрисовки на любом масштабе.
3. Должна корректно смотреться в светлой и тёмной теме без отдельных
   тёмных/светлых цветов, зашитых напрямую (через существующие
   CSS-переменные).
4. Существующее поведение — disabled-состояние (прозрачность, no-pointer-
   events), скрытие в custom-периоде, aria-label, обработчики клика —
   без изменений.

## Критерии готовности

- Визуально соответствует референсу: круглая обводка + шеврон.
- Клик по кнопке по-прежнему переключает месяц (`shiftPeriod`), disabled-
  кнопка (следующий месяц = текущий) не кликабельна.
- Светлая и тёмная тема — корректный контраст без правок.
- Нет ошибок в консоли.

## План проверок

1. Синтаксическая проверка инлайн-скрипта.
2. Визуальная проверка в браузере предпросмотра (светлая/тёмная тема).
3. Клик по кнопке «назад»/«вперёд» — проверка смены месяца и данных
   карточки/списка.
4. Проверка консоли на ошибки.

## Доработка в той же задаче: убраны круг/фон/обводка, системный синий/серый

Пользователь после визуальной проверки первой реализации (круглая кнопка
с обводкой) попросил упростить: оставить только сам SVG-шеврон, без круга,
фона и обводки вокруг — активные стрелки системным синим (в стиле iOS),
отключённая стрелка — светло-серой с пониженной прозрачностью. Логику
переключения/disabled не менять.

### Реализация

- `index.html`, CSS `.month-switch .m-arrow`:
  - `border:1.6px solid var(--text);border-radius:50%` → `border:none`
    (круг и обводка убраны, разметка/размер кнопки `38×38` — та же зона
    нажатия, что и в первой реализации).
  - `color:var(--text)` → `color:var(--nav-blue)` — переиспользован уже
    существующий в проекте токен «системного синего» (используется для
    активной вкладки нижней навигации и текста активного периода;
    `#4f7df0` светлая тема / `#5b8bff` тёмная), а не новый цвет.
  - `:active{background:var(--card2)}` → `:active{opacity:.55}` — тактильная
    обратная связь по нажатию без фонового «пятна» (фона у кнопки больше
    нет).
  - `:disabled{opacity:.3;...}` → `:disabled{color:var(--muted2);
    opacity:.5;...}` — светло-серый (`var(--muted2)`, тот же токен, что и
    вторичный серый текст в остальном приложении) плюс дополнительно
    пониженная прозрачность.
  - `:focus-visible` outline и сами SVG-иконки (viewBox/paths) не менялись.
  - Обработчики `onclick`/`shiftPeriod`, `disabled`/`aria-label`-логика в
    `renderFinanceCard()` — не тронуты.
- `sw.js`: версия кэша поднята `finance-v146` → `finance-v147` (совместно
  с `TASK_006`, т.к. оба изменения попали в один и тот же `index.html`
  перед публикацией).

### Проверки выполнены

- Синтаксис инлайн-скрипта — без ошибок.
- Браузер предпросмотра (375×812, светлая и тёмная тема):
  - Светлая тема: активная стрелка — `rgb(79, 125, 240)` (`var(--nav-blue)`
    светлой темы), без круга/фона/обводки (`border-style:none`,
    `background-color:rgba(0,0,0,0)`); отключённая стрелка —
    `rgb(154, 160, 176)` (`var(--muted2)`), `opacity:0.5`.
  - Тёмная тема: та же проверка — активная стрелка светло-синяя (тёмный
    вариант `var(--nav-blue)`), отключённая — серая/приглушённая, без
    правок под тему (переиспользованы существующие токены).
  - Переключение месяца (`fcMonthPrev`/`fcMonthNext.click()`): «Июль
    2026 г.» → «Июнь 2026 г.» → обратно «Июль 2026 г.», при этом
    disabled-стрелка корректно становится активной (синей) на не-текущем
    месяце и снова отключается (серая/`opacity:0.5`) на текущем — поведение
    идентично состоянию до правки, только цвет/отсутствие круга изменились.
  - Совместно проверена работа `TASK_006` (фиксированная шапка,
    `#scrollArea`) — `topbarTop` остаётся `0` при скролле, `.scrolled`
    переключается корректно.
  - Ошибок в консоли браузера нет.
