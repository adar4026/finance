## 4. Цель

Полностью визуально привести экран «Категории» к стилю Главной страницы:
единый фон, карточки, синий Liquid Glass переключатель Расходы/Доходы,
более плавный (spring, FLIP, дополнительный haptic) drag & drop,
более современная иконка ручки перетаскивания, микроанимации нажатия.
Кнопка закрытия уже унифицирована — не трогается.

## 8. Реализация

### 8.1. Изменённые файлы

- `index.html`:
  - `#catMgrOverlay .detail-sheet{background:var(--home-bg)}` — фон
    экрана «Категории» теперь тот же светло-серый, что и на Главной
    (`#scrRecords`); общий класс `.detail-sheet`, используемый другими
    overlay-экранами (детали счёта, статистика и т.д.), не изменён —
    правило специфично для `#catMgrOverlay`.
  - `.cat-row` — добавлена `box-shadow:var(--fincard-shadow)` (тот же
    токен минимальной тени, что у `.fincard`/`.acc2`), радиус увеличен
    `15px → 18px` (согласован с `.drawer-card`/`.acc2`), отступы
    `14px → 15px 16px`, добавлена микроанимация нажатия
    (`transform:scale(.985)` на `:active`, приём как у `.acc2:active`).
    Данные строки (эмодзи, название, число подкатегорий, «системная») —
    без изменений разметки/логики.
  - `.cat-row.cat-lift` — убрана цветная рамка `border:2px solid
    var(--accent)`, оставлены только тень+масштаб (спокойный Apple-стиль
    подъёма), отдельное более тёмное значение тени для `[data-theme=
    "dark"]`.
  - `.cat-handle` — заменены три `<span>`-полоски на SVG grip-иконку
    (2×3 точки, `fill:currentColor`, в общем stroke/fill-стиле SVG-иконок
    приложения, TASK_017); добавлен класс `.grabbing` (увеличение
    `scale(1.18)` + цвет `var(--text)` вместо `var(--muted2)`) на время
    захвата.
  - `.cat-ph` — смягчён (сплошной `var(--card2)` вместо пунктирной рамки
    акцентного цвета), радиус согласован с `.cat-row` (18px).
  - `#catMgrSeg` — разметка заменена с `.seg-ie` (сплошная заливка
    активной кнопки) на `.periods` + `.periods-indicator`
    (`#catMgrSegInd`) — тот же компонент/стиль, что переключатель
    «День/Неделя/Месяц/Год/Период» на Главной (синее Liquid Glass,
    `--nav-glass-*`/`--nav-blue`). Новая функция
    `moveCatMgrSegIndicator(instant)` (по образцу
    `movePeriodsIndicator()`/`moveTxSegIndicator()`) подключена: в
    `openCatMgr()` (после показа overlay, `instant=true`), в обработчик
    клика по кнопкам сегмента (анимированно), в общие `resize`/
    `orientationchange` обработчики и в новый `ResizeObserver` для
    `#catMgrSeg` — по аналогии с `#periods`/`#txSeg`.
  - `setupCatSort()`/`liftCatCard()` — сигнатура расширена параметром
    `handle` (для toggle класса `.grabbing`); добавлен короткий
    spring-переход (`transition:transform .22s cubic-bezier(.34,1.3,.4,
    1)`) на «взлёт» карточки при захвате, снимается через 220мс, после
    чего управление transform полностью переходит к существующему
    rAF-циклу слежения за пальцем (без transition — иначе слежение
    отставало бы).
  - Новая функция `flipCatRows(mutate)` — FLIP-анимация (First-Last-
    Invert-Play) для соседних `.cat-row` при каждом реальном сдвиге
    плейсхолдера в `move()` (раньше — мгновенный скачок без анимации);
    вызывается только когда точка вставки плейсхолдера действительно
    меняется (`target!==ph.nextSibling`), не на каждый `pointermove`.
  - `up()` — конечная посадка карточки переведена на тот же
    spring-easing (`cubic-bezier(.34,1.05,.4,1)`, 320мс вместо 200мс);
    добавлен второй `navigator.vibrate(12)` после успешного отпускания,
    **только если порядок реально изменился** (сравнение исходной и
    финальной последовательности id категорий, захваченной в начале и
    конце `liftCatCard()`).
  - **Найден и исправлен смежный баг**, блокировавший любой reorder:
    `commitCatOrder()` вызывала `$$('#catMgrList .cat-row').map(...)`,
    а `$$` в этом файле (`const $$=s=>document.querySelectorAll(s)`)
    возвращает `NodeList`, у которого нет `.map()` — при **любом**
    отпускании перетаскиваемой карточки бросался `TypeError` внутри
    обработчика `pointerdown`/`up`, из-за чего drag-and-drop категорий
    не работал вообще ни разу (обнаружено при верификации в браузере,
    воспроизведено прямым вызовом `liftCatCard()` из консоли). Исправлено
    на `[...$$(...)].map(...)` — как в этом месте, так и в двух новых
    местах (`origSeq`/`newSeq`), где по невнимательности был скопирован
    тот же паттерн. Это входит в границы задачи («Drag & Drop —
    сделать полноценное плавное изменение порядка категорий» прямо
    требует, чтобы reorder работал).
  - `renderCatMgr()` — обновлена только разметка `.cat-handle` (SVG
    вместо `<span>`), логика/данные строк не изменены.
  - Кнопка `#catMgrClose` — **не изменена**: уже использовала общий
    `.iconbtn`, тот же класс, что и все остальные overlay-экраны.
- `sw.js` — `CACHE`: `finance-v160` → `finance-v161`.

## 10. Известные ограничения

- Реальная проверка drag & drop на iPhone Safari/PWA (touch-события,
  haptic через `navigator.vibrate`, которого на iOS Safari нет — там
  используется системный haptic из `<input type="range">`-подобных API
  недоступен; на iOS `navigator.vibrate` тихо не выполняется, это
  ожидаемо и не является регрессией, т.к. и предыдущий вызов на
  захвате был в коде уже до `TASK_018`) не выполнена в этой сессии —
  drag протестирован через реальный (trusted) курсорный drag в Chromium
  (`computer.left_click_drag`), не через touch-эмуляцию.
- Редактор категории (`#catEditOverlay`) не входит в ТЗ и не
  редизайнился — визуально остаётся в прежнем стиле.
