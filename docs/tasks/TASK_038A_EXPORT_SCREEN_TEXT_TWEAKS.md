## 1. Контекст

Небольшой корректирующий follow-up к `TASK_038` (не занимает номер
`TASK_039` — тот же приём, что `TASK_017A`/`TASK_003A`). По итоговой
правке пользователя нужно изменить две подписи на экране «Экспорт и
копии»: убрать упоминание стороннего приложения Money Flow в карточке
импорта CSV и сделать подпись карточки создания резервной копии более
профессиональной. Архитектура, логика и остальные тексты `TASK_038`
(парсер CSV, мастер импорта, mapping, duplicate detection, backup
envelope, restore flow) не затрагиваются.

## 2. Цель

Точечно изменить подписи двух карточек на экране «Экспорт и копии»:

1. `#impCsvBtn` — убрать конкретное упоминание Money Flow, сделать
   нейтральной: «Из приложений и банков, поддерживающих CSV».
2. `#bkpCreate` — заголовок «Создать копию» → «Создать резервную копию»,
   подпись «Полная копия всех данных, файл .afb» → «Все данные
   приложения · .afb».

Карточка `#bkpRestore` («Восстановить из копии» / «Заменит все текущие
данные приложения») уже соответствует требуемой формулировке —
не изменяется.

## 3. Границы

**Включено:**
- Текст `<i>` внутри `#impCsvBtn` в `index.html`.
- Текст `<b>` и `<i>` внутри `#bkpCreate` в `index.html`.

**Явно исключено (не трогать):**
- Формат `.afb`, envelope/checksum/migration (`js/services/backup_service.js`).
- CSV-парсер, мастер импорта, column/account/category mapping,
  duplicate detector (`js/services/csv_parser_service.js`,
  `import_source_service.js`, `import_mapping_service.js`,
  `import_service.js`).
- Restore flow (safety-копия → миграция → запись → сверка → успех).
- XLSX/CSV/PDF export (`js/services/export_service.js`,
  `js/services/xlsx_writer_service.js`).
- Rollback/atomic apply, `SCHEMA_VERSION`, версия кэша `sw.js`.
- Разметка/CSS структуры экрана (порядок разделов Экспорт → Импорт
  данных → Резервные копии, destructive-стиль `#bkpRestore`), id
  элементов, обработчики.
- Внутренние комментарии кода, упоминающие Money Flow как источник
  вдохновения для демо-данных/форматирования (не пользовательский UI,
  вне контракта задачи).
- `<title>Финансы — Money Flow</title>` — заголовок вкладки браузера,
  не часть экрана «Экспорт и копии», вне запроса пользователя.

## 4. Требования

- Смысл сохраняется: CSV = обмен данными между приложениями, `.afb` =
  собственная полная резервная копия A-Lex Finance. Форматы не
  объединяются, `.afb` не заменяется на CSV нигде в тексте.
- Никакой сторонний бренд не упоминается в пользовательском UI.
- Тексты не переполняют карточку и корректно переносятся на mobile
  viewport, light/dark theme без изменений (используются существующие
  токены).
