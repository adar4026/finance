# TASK_062 — Нижняя навигация: материал iOS Liquid Glass

**Статус:** DONE (закоммичено, не опубликовано)

## Контекст

Нижняя навигация уже плавающая капсула (`.nav`, TASK_056/057): пять реальных
вкладок (Главная, Аналитика, Записи, Счета, Бюджеты), общая pill активной
вкладки (`#navIndicator`), drag-жест, отдельная кнопка «＋» (`#addBtn`,
`openSheet(null)`). Дублей навигации нет; «Ещё»-меню нет — доп. разделы живут в
боковой шторке (аватар). Задача — не пересобирать, а довести **материал**
до iOS Liquid Glass: заметное размытие фона под панелью (сейчас blur 2px,
заливка .03 — панель почти невидима на сложном фоне), нейтральная плотная
подложка активной вкладки, крупнее иконки/подписи.

## Границы работы

Разрешено: токены `--nav-*` и CSS блока `.nav` / `.nav button` /
`.nav-indicator` / `.nav-add` в `index.html`; `tests/bottom_nav_glass_drag.test.js`
(ожидания значений); `sw.js` cache version + `?v=` в `index.html`;
`js/core/app_info.js`; `CHANGELOG.md`; документация.

Запрещено: JS `navDrag` / `moveNavIndicator` / `showScreen`, разметка вкладок,
маршруты, экраны, бизнес-логика, `--nav-glass-*` (`.periods-indicator`),
новые зависимости.

## Требования

1. Light: `--nav-bg` ≈ `rgba(255,255,255,.62)`, blur ≈ 22px, saturate 160%,
   светлый контур, мягкая тень; dark — тёмная полупрозрачная без белой подложки.
2. Pill — нейтральная подложка темнее стекла (light — тёмный tint, dark —
   светлый tint), иконка/подпись активной — акцент `--nav-active`.
3. Иконка 24px, подпись 12px (узкие экраны — меньше), без обрезки «Аналитика».
4. Высота капсулы/геометрия pill (64px / padding 7px) и safe-area — без изменений.
5. Кнопка «＋» — тот же материал.
6. Контент не перекрывается (`.scroll-area` padding-bottom уже учитывает `--navh`).

### Финальная проверка (2026-10-17, превью Chromium, не iPhone/Safari)

- Размеры 320/375/390/430, light и dark: overflow нет, подписи не обрезаны,
  5 вкладок переключаются, активная всегда одна, `.nav` один. На 320px
  кнопки 56×48, подпись 9.5px.
- Контраст активной вкладки на серой подложке был ≈3.8:1 (light) / ≈3.7:1
  (dark) — исправлено: `--nav-active` light `#2f5bd8`, dark `#7fa3ff` (≥4.5:1).
- Блюр поверх длинного списка операций: суммы под капсулой размыты и
  приглушены, но различимы.
- PWA: единственный кэш `finance-v194`, в нём новый `index.html` (без старых
  токенов) и `js/…?v=194`; CSS inline в `index.html` — конфликта старого и
  нового CSS быть не может; localStorage (33 операции) сохранён после
  перезагрузки; стратегия SW не менялась.
- «＋» внутри капсулы не реализована: требует правок разметки и JS (`navDrag`,
  `--nav-count`) и не помещается на 320px — ждёт решения.

### Решение по «＋» и коммиты

помещается на 320px и требует правок JS/разметки). Коммит реализации:
`fddbfcf` — `feat(TASK_062)`. Публикация — после отдельного разрешения;
перед production желательна проверка на реальном iPhone (Safari backdrop-filter).
