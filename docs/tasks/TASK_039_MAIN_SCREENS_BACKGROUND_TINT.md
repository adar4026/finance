# TASK_039 — Основные экраны: мятно-серо-зелёный фон вместо почти белого

## 1. Контекст

Точечная визуальная правка по прямому запросу пользователя, вне
очереди `TASK_025` §12 (тот же приём, что `TASK_038`/`TASK_038A`/
`TASK_038B` — задача выполняется по запросу пользователя, а не по
плану). Фон основных экранов приложения (`--home-bg:#f2f2f7` в светлой
теме) выглядит почти белым и не даёт белым карточкам достаточно
отделиться от подложки. Пользователь прислал референс: верхняя часть
страницы — насыщенный холодный мятный `#D1E4DB`, основная нижняя
область — светлый серо-зелёный `#EBF0ED`, с очень мягким вертикальным
переходом между ними, без резкой полосы.

## 2. Цель

Сделать фон четырёх основных экранов (Главная/Записи, Аналитика,
Счета, Бюджеты) заметно более насыщенным холодным мятно-серо-зелёным,
с мягким вертикальным градиентом сверху вниз, приближенным к
референсу пользователя, не трогая структуру, карточки, тени,
типографику, кнопки, бизнес-логику и тёмную тему.

## 3. Границы

**Включено:**
- Новые CSS-токены фона основных экранов в `:root, [data-theme="light"]`
  (не переопределение существующего `--home-bg`, чтобы не задеть
  побочных потребителей).
- Аналогичные токены в `[data-theme="dark"]`, зафиксированные на
  прежнем значении `--home-bg`, чтобы тёмная тема была визуально
  идентична текущей (явное требование — «если есть dark theme — её не
  менять»).
- Правила фона `#scrRecords`, `#scrCharts`, `#scrAccounts`,
  `#scrBudgets` и парные `.scroll-area:has(>#scrX.active)` — замена
  `var(--home-bg)` на новый градиентный токен.

**Явно исключено (не трогать):**
- Глобальный токен `--home-bg` и все его прочие потребители: `.drawer`,
  `.prof-page` (Профиль), `.secp-page` (Безопасность),
  `#catMgrOverlay .detail-sheet` (Категории), `--tx-page-bg` (страница
  операции) — они продолжают использовать прежний `--home-bg:#f2f2f7`
  без изменений.
- `.topbar` (остаётся `var(--bg)` — белая, sticky) — референс относится
  к области ниже шапки.
- Тёмная тема — визуально не меняется ни в одном из перечисленных мест.
- Белые карточки (`.fincard`, `.panel`, `.acc-cat`, `.bud-card` и т.д.),
  тени, радиусы, отступы, шрифты, цвета кнопок, `.capital`-градиенты,
  бизнес-логика, расчёты, данные, сервисы, `SCHEMA_VERSION`.
- Разметка/структура экранов, id элементов, обработчики.

## 4. Требования

- Верхняя часть — насыщенный холодный мятный `#D1E4DB`.
- Плавный переход в светлый серо-зелёный `#EBF0ED`, без видимой полосы
  градиента (двухточечный `linear-gradient` без резких стопов).
- Фон не выглядит ярко-зелёным или «грязным».
- Карточки читаются не хуже, чем сейчас (контраст белых карточек с
  новым фоном увеличивается, а не уменьшается).
- Контраст текста не ухудшается ни на одном из четырёх экранов.
- Fixed/sticky нижняя навигация не получает случайный другой фон.
- Нет белых полос между секциями/под навигацией на длинном скролле.
- Дизайн-токены переиспользуются между всеми четырьмя экранами (не
  четыре независимых копии цвета).

## 5. Критерии готовности

- Изменения ограничены `<style>`-блоком `index.html` (новые токены +
  8 правил `background`), без правок JS/сервисов/HTML-разметки.
- Полный regression suite зелёный без изменений (тексты/структура не
  затронуты — тесты не должны были сверять цвет фона дословно; если
  выяснится обратное — тест переписывается на инвариант, а не
  отключается).
- Проверено в браузере на мобильной ширине (375×812), светлая тема:
  все четыре экрана, длинный скролл, карточки, нижняя навигация,
  переход между вкладками.
- Тёмная тема проверена на отсутствие визуальных отличий от
  предыдущей версии.
- Консоль браузера без новых ошибок.
- `git diff` — только точечные правки фона в `index.html`.

## 7. Фактический результат

Добавлены три новых CSS-токена в `:root, [data-theme="light"]` (`index.html`,
рядом с `--home-bg`): `--main-bg-top:#D1E4DB`, `--main-bg-bottom:#EBF0ED`,
`--main-bg-grad:linear-gradient(180deg,var(--main-bg-top) 0%,
var(--main-bg-bottom) 380px)`. Двухточечный градиент без промежуточных
стопов не даёт видимой полосы; после 380px CSS оставляет плоский
`--main-bg-bottom` до конца бокса (спецификация `linear-gradient`: цвет
после последнего стопа остаётся постоянным) — поэтому длинный скролл не
показывает повторов/швов градиента.

`--home-bg` **не тронут** — в `[data-theme="dark"]` три новых токена
явно зафиксированы на прежнем значении (`--main-bg-top:var(--home-bg)`,
`--main-bg-bottom:var(--home-bg)`, `--main-bg-grad:var(--home-bg)`), поэтому
тёмная тема резолвится в тот же `#171a21`, что и раньше (проверено
инструментально — `getComputedStyle` в браузере даёт побайтово совпадающие
значения).

Заменено `background:var(--home-bg)` → `background:var(--main-bg-grad)`
в восьми местах: `#scrRecords`/`.scroll-area:has(>#scrRecords.active)`,
`#scrCharts`/тот же приём, `#scrAccounts`/тот же приём,
`#scrBudgets`/тот же приём. `.scroll-area`-правило использует тот же токен,
что и сам экран — зона под sticky-навигацией остаётся тем же плоским
цветом, что нижняя часть градиента, без видимого шва. Все прочие
потребители `--home-bg` (`.drawer`, `.prof-page`, `.secp-page`,
`#catMgrOverlay .detail-sheet`, `--tx-page-bg`) не изменены ни строкой.

`tests/budgets_screen.test.js` §1 сверял фон дословной строкой
`var(--home-bg)` — переписан на инвариант (тот же токен, что у
`#scrRecords`, каким бы он ни был), а не отключён; остальные тесты текст
фона нигде дословно не проверяли.

**Проверки:**

1. Полный regression suite: **1582 passed, 0 failed** в 20 файлах (было
   1581 — ровно одна новая проверка добавлена в переписанном §1
   `budgets_screen.test.js`, ни одна не удалена).
2. Браузер (`localhost:8912`, чистый origin, мобильный viewport 375×812,
   светлая тема): Главная, Аналитика, Счета, Бюджеты — на всех четырёх
   виден мягкий переход от насыщенного мятного сверху к светлому
   серо-зелёному, без заметной полосы; белые карточки читаются
   заметно лучше, чем на прежнем `#f2f2f7`; на «Бюджетах» (пустое
   состояние, длинный пустой хвост) фон однородно продолжается до
   нижней навигации без белых полос; переключение между вкладками —
   фон везде идентичный.
3. Браузер, тёмная тема: переключение `data-theme="dark"` на Главной —
   визуально неотличимо от исходной версии; `getComputedStyle` подтвердил
   побайтовое совпадение `--main-bg-grad` и `--bg2` (`#171a21`).
4. Консоль браузера: новых ошибок нет — только предсказуемый CORS-шум
   стороннего аналитического скрипта окружения (`cloudflareinsights.com`),
   не относящийся к приложению (тот же фоновый шум наблюдался при
   верификации `TASK_038A`).
5. `git diff` — точечные правки: `index.html` (токены + 8 правил фона),
   `tests/budgets_screen.test.js` (§1 переписан на инвариант),
   `CHANGELOG.md` (запись Unreleased), `docs/PROJECT_STATUS.md`,
   `docs/ROADMAP.md`. `.claude/launch.json` и `icon.svg` — несвязанные
   локальные изменения, не тронуты (в `launch.json` добавлена только
   новая независимая запись `finance-local` для превью на этой машине,
   существующие записи не изменены).

**Известные ограничения:** реальная проверка на iPhone не выполнялась в
этой сессии (виртуальный мобильный viewport воспроизводит только layout,
не цветопередачу реального экрана/условий освещения) — рекомендуется
пользователю подтвердить оттенок на реальном устройстве после публикации.
