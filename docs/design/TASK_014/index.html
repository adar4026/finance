TASK_014 — концепции страницы операции

Дизайн-референсы, подготовленные на этапе 2 TASK_014 для выбора направления редизайна полноэкранной страницы добавления/редактирования операции. Открывать на ширине iPhone (≈393px).

Только статические дизайн-референсы, не production-код. Эти HTML-файлы — архив истории решения TASK_014 (см. docs/tasks/TASK_014_TX_PAGE_PREMIUM_REDESIGN.md), а не часть приложения:
  • не подключены к index.html, не импортируются и не линкуются оттуда никаким образом;
  • не зарегистрированы в sw.js — отсутствуют в списке ASSETS и не кэшируются PWA service worker'ом;
  • не используют AF.Store/сервисы приложения — разметка и данные на них зашиты статически, только для визуальной оценки;
  • реализована в production — только гибрид, и не копированием этого файла, а отдельной вёрсткой внутри #overlay в index.html с сохранением всей существующей бизнес-логики.
Утверждённый гибрид Реализовано
Основа B (стекло только на header, segmented и футере) + структура и спокойная типографика суммы из A. Есть переключатель светлой/тёмной темы (кнопка ◐ в правом верхнем углу) и вторичное «Удалить операцию». Именно эта концепция реализована в production (не путём подключения этого файла — см. предупреждение выше).
Концепция A — Apple Minimal
Светлый системный фон, белые непрозрачные карточки, минимум теней, строгая типографика, цвет только у типа операции, суммы и основного действия.
Концепция B — Apple Liquid Finance
Серо-молочный фон с мягким холодным свечением, стеклянные header, segmented control и футер, сумма окрашена по типу операции, мягкая глубина.
Концепция C — Premium Banking
Нейтрально-тёплый фон, строгие карточки с тонким stroke, почти чёрная типографика, подчёркивание вместо капсулы в переключателе, графитовая кнопка.
