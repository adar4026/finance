## Технологический стек

- Чистые **HTML / CSS / JavaScript**, без сборки и без фреймворка (React/Vue/etc отсутствуют).
- Единственная внешняя зависимость — **Chart.js 4.4.1**, подключается с CDN
  (`cdn.jsdelivr.net`) и кэшируется service worker'ом для офлайн-работы.
- Шрифты — системные (`-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Inter`).
- Иконки — inline SVG, без иконных библиотек.

## Архитектура

Слоистая архитектура, явно спроектированная как «feature-ready» для будущего
переноса на Flutter (см. комментарии в коде):

```
core/       → js/core/result.js, js/core/app_info.js
database/   → js/database/store.js   (репозиторий поверх localStorage)
services/   → js/services/*.js       (currency, account, analytics,
                                       budget, goal, forecast,
                                       health_score, export, backup)
UI          → index.html (разметка, стили, обработчики) —
              обращается только к AF.Store / AF.Services, не к localStorage напрямую
```

`AF.AppInfo` (`js/core/app_info.js`) — единая точка правды для имени
приложения, номера версии и даты релиза; UI читает эти значения, а не
хардкодит их.

## Хранение данных

- Данные пользователя хранятся **локально в браузере** через `localStorage`
  (ключ `finance_app`), доступ — только через `AF.Store` (`js/database/store.js`).
- Есть версионирование схемы (`schemaVersion`) и функция миграции (`migrate`),
  сохраняющая данные пользователя при обновлении структуры.
- Бэкап/восстановление и экспорт/импорт реализованы поверх этого же хранилища
  (`js/services/backup_service.js`, `js/services/export_service.js`).

## Публикация

- Статический сайт, публикуется через **GitHub Pages** из ветки `main`
  (репозиторий `adar4026/finance`), без CI/CD workflow — файлы обслуживаются
  напрямую из корня репозитория.
- Продакшен-адрес: https://adar4026.github.io/finance/

## Поддержка PWA

- `manifest.json`: имя «Финансы — учёт доходов и расходов», `display: standalone`,
  `orientation: portrait`, иконки 192/512, `lang: ru`.
- `sw.js`: service worker с network-first стратегией кэширования (сеть в
  приоритете, при офлайне — отдаёт закэшированное); версия кэша на baseline —
  `finance-v138`.
- Установка на экран (`apple-touch-icon`, `apple-mobile-web-app-capable`,
  `mobile-web-app-capable`), кастомные `theme-color` для светлой и тёмной темы.
- Есть конфигурационные профили `.mobileconfig` в корне репозитория (вне зоны
  документации — не анализировались подробно в рамках baseline).

## Основные экраны (подтверждено `index.html`)

- **Главная** (`#scrRecords`) — верхняя панель (аватар → поиск → аналитика),
  сворачиваемый sticky header, карточка сводного баланса, список операций,
  сгруппированный по дням.
- **Аналитика** (`#scrCharts`) — графики на Chart.js.
- **Счета** (`#scrAccounts`) — список счетов пользователя.
- **Бюджеты** (`#scrBudgets`) — месячные лимиты по категориям.
- **Ещё / профиль** (`#scrMore`) — настройки, экспорт/импорт, доступ к целям
  и календарю.
- **Боковая панель (drawer)** — открывается по аватару, показывает профиль,
  карточку общего капитала со спарклайном, пункты меню (уведомления, цели,
  календарь, тема, экспорт и копии) и блок Release Information внизу.
- **Шторка добавления/редактирования операции** — сегменты «Расход / Доход /
  Перевод», выбор категории и подкатегории, отдельный режим перевода между
  счетами.

## Реализованные пользовательские функции

Подтверждено кодом (`js/services/*`) и `CHANGELOG.md` (раздел 1.0.0):

- Счета (Accounts), в т.ч. мультивалютные, с архивированием.
- Операции (Transactions): доходы, расходы, переводы между счетами.
- Категории и подкатегории операций.
- Аналитика (`analytics_service.js`) с визуализацией через Chart.js.
- Бюджеты — месячные лимиты по категориям (`budget_service.js`).
- Цели (Goals) — целевые накопления с прогрессом (`goal_service.js`).
- Календарь операций (доступен из профиля, `profCalendar`).
- Финансовое здоровье — health score/ring (`health_score_service.js`).
- Прогноз (`forecast_service.js`).
- Поиск (капсула поиска в шапке главного экрана).
- Импорт/экспорт данных (JSON/CSV) и резервное копирование
  (`export_service.js`, `backup_service.js`).
- Мультивалютность с приведением к базовой валюте (`currency_service.js`).
- Светлая и тёмная тема, переключается из профиля.
- Офлайн-режим как устанавливаемое PWA.

## Темы оформления

- Светлая и тёмная тема реализованы через `data-theme` на `:root` и полный
  набор CSS-токенов (`--bg`, `--card`, `--accent`, `--income`, `--expense`
  и т.д.) для обеих тем.
- Тема по умолчанию — светлая (см. `AF.Store` → `theme: 'light'`).
- Переключение темы — пункт профиля (`#profTheme`).

## Навигация

- Нижняя навигация — плавающая капсула с пятью элементами: «Главная»,
  «Аналитика», центральная кнопка «Добавить» (+), «Счета», «Бюджеты».
  Подробности реализации и история доводок — см.
  [`docs/tasks/TASK_001_HOME_NAVIGATION.md`](tasks/TASK_001_HOME_NAVIGATION.md).
- Верхняя панель — collapsing/sticky header с аватаром, поиском и кнопкой
  аналитики.
