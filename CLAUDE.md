# CLAUDE.md — A-Lex Finance

Обязательная точка входа для Claude Code перед любыми изменениями в этом
репозитории. Полный рабочий процесс — в [`AGENTS.md`](AGENTS.md).

Перед любыми изменениями обязательно:

1. Прочитать [`AGENTS.md`](AGENTS.md).
2. Прочитать [`docs/PROJECT_BASELINE.md`](docs/PROJECT_BASELINE.md).
3. Прочитать [`docs/PROJECT_STATUS.md`](docs/PROJECT_STATUS.md).
4. Прочитать [`docs/ROADMAP.md`](docs/ROADMAP.md).
5. Определить текущую активную задачу.
6. Открыть соответствующий TASK-файл в `docs/tasks/`.
7. Проверить состояние Git (`git status`, текущая ветка, `HEAD`, синхронизация с `origin/main`).
8. Не начинать реализацию без созданной и оформленной задачи.
9. После выполнения — записать фактический результат и проверки в TASK-файл.
10. Не переходить к следующей задаче до закрытия текущей.

Подробные правила статусов, границ и формата коммитов — см. `AGENTS.md`.
